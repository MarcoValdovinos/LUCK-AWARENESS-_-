# 🚨 Protocolo de Respuesta a Incidentes (Para el Usuario)

Si caíste en una estafa, sigue estos pasos:

1. **No borres nada:** Conserva los mensajes.
2. **Genera la evidencia:** Usa KRONOS Luck-Awareness para generar el reporte HTML.
3. **Contacta a tu banco:** Si compartiste datos financieros, congela tus tarjetas.
4. **Cambia contraseñas:** Si diste acceso a cuentas (Google, Microsoft, etc.), cámbialas inmediatamente y activa el 2FA.
5. **Denuncia:**
   - En México: Llama al 088 (Guardia Nacional Cibernética) o acude a la Fiscalía.
   - En España: Contacta a INCIBE (017).
   - A nivel global: Reporta a la plataforma (Google, Meta, etc.).
6. **Presenta el reporte:** El archivo HTML que generó KRONOS tiene el Hash SHA-256 para demostrar que la evidencia no ha sido alterada ante las autoridades.

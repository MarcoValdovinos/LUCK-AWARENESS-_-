# 🛡️ KRONOS LUCK-AWARENESS

> *Herramienta de ciberseguridad forense para detectar, documentar y reportar fraudes digitales.*

## 🎯 ¿Qué es esto?
KRONOS Luck-Awareness es una aplicación web **100% local (Client-Side)** diseñada para analizar mensajes sospechosos (correos, SMS, WhatsApp) en busca de patrones de estafa, phishing o esquemas piramidales. Genera evidencia forense (hash SHA-256) y reportes listos para presentar ante autoridades.

**No promete suerte. No promete riqueza. Detecta y documenta fraudes.**

## ✨ Características
- 🔍 **Detector de Banderas Rojas:** Analiza urgencia, secreto, promesas de riqueza y amenazas.
- ⚖️ **Score de Riesgo:** Clasifica el mensaje en Bajo, Medio, Alto o Crítico.
- 🔐 **Evidencia Criptográfica:** Calcula el hash SHA-256 del mensaje para garantizar que no sea alterado.
- 📄 **Reporte Forense:** Exporta un archivo HTML con toda la evidencia lista para un abogado o denuncia.
- 🔒 **Privacidad Total:** Ningún texto se envía a servidores externos. Todo ocurre en tu dispositivo.
- 📱 **PWA (Instalable):** Funciona sin conexión a internet.

## 🚀 ¿Cómo usarlo?
1. Abre la aplicación en tu navegador.
2. Pega el mensaje sospechoso en el área de texto.
3. Haz clic en "Analizar Riesgo".
4. Revisa el nivel de amenaza y las banderas rojas.
5. Haz clic en "Guardar Evidencia y Generar Reporte".
6. Se descargará un archivo `.html` con el reporte forense.

# 📅 Historial de Cambios

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2026-11-04
### Agregado
- Lanzamiento inicial de la arquitectura Core.
- Interfaz de usuario con diseño responsivo y accesible.
- Motor de detección de banderas rojas (`red-flag-detector.js`).
- Calculadora de score de riesgo (`risk-score.js`).
- Generador de hashes SHA-256 para evidencia (`hash-utils.js`).
- Sistema de generación de reportes descargables en HTML (`report-generator.js`).
- Soporte PWA (Service Worker y Manifest) para uso offline.
